## 3. Касса самообслуживания (checkout.cpp)

**Тест 1 (цена 1350, количество 4, внесено 5000)**

Сумма: 5400, скидка 10%, к оплате: 4860
Оплата прошла
Сдача: 140 руб
Категория: существенная скидка

**Тест 2 (цена 900, количество 4, внесено 3000)**

Сумма: 3600, скидка 5%, к оплате: 3420
Недостаточно средств: ещё 420 руб
Категория: обычная покупка

**Тест 3 (цена 700, количество 1, внесено 700)**

Сумма: 700, скидка 0%, к оплате: 700
Оплата прошла
Сдача: 0 руб
Категория: обычная покупка

**Проверка версии со скидкой-тернарником:**
Итоговая формула `int percent = sum > 5000 ? 10 : (sum > 1000 ? 5 : 0);` на всех трех тестах выдает те же значения (10%, 5% и 0%). К оплате не меняется.
Оценка читаемости: обычный `if / else if` читается проще, особенно если скидок станет пять. Вложенные тернарные операторы быстро становятся нечитаемыми.


## Объяснения поведения

**Почему скидка 0% не портит сумму:**
Формула скидки `sum * percent / 100` при `percent = 0` дает `sum * 0 / 100 = 0`. Вычитание нуля не меняет исходную сумму.

**Почему границы скидки проверяются «больше» ( > ), а не «больше или равно» ( >= ):**
Если бы стояло `>= 5000`, то сумма ровно 5000 рублей уже получила бы скидку 10%. По условию скидка 10% положена при сумме *строго больше* 5000.
