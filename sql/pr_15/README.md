# Отчет по ПР15. Переменные и табличные файлы

## Часть 1. Переменные в SQL-скрипте
В качестве замены переменных сеанса (которых нет в чистом SQLite) я использовал CTE (Common Table Expressions).
*   Максимальный залог из таблицы `rentals` равен **1000**.
*   Общее количество выдач: **3**.

## Часть 2. Программный файл (Перезапускаемость)
Скрипт `pr15.sql` использует `DROP TABLE IF EXISTS` перед созданием таблиц. При двойном запуске скрипт не выдает ошибок, данные не дублируются.
*   Контрольные числа после создания песочницы: `COUNT(*)` = **6**, `MAX(price_per_day)` = **390**, `AVG(price_per_day)` = **220.0**.

## Часть 3. «Массив»: CTE и Временная таблица
*   **Числа из массива (batch):** Количество строк = **3**, максимальная цена = **420**.
*   **Отличие CTE от временной таблицы:** CTE существует только внутри одного запроса (оператора), а временная таблица живет в течение всей сессии и может использоваться в нескольких запросах подряд.
*   **Запрос позиций дороже 200 руб:** результат на CTE и на временной таблице совпал (1 позиция — Перфоратор SDS-Plus за 420).
*   **UPDATE из массива:** Обновилась **1** строка (цена «Стремянки 3 м» изменилась со 120 на **130**).

## Часть 4. Заполнение массива из табличного файла (CSV)
*   После импорта `tools_batch.csv` в таблицу `tools_stage` находится **3** строки.
*   Запрос `INSERT ... SELECT` с защитой `NOT EXISTS` вставил в каталог **2** строки. Не вставились 3, потому что позиция «Стремянка 3 м» уже была в каталоге (мы обновили её цену в Части 3), и условие `NOT EXISTS` её отфильтровало.
*   **Наблюдение при поломке файла:** Если убрать запятую в CSV-файле, СУБД (SQLite) при импорте обычно сдвигает колонки (данные попадают не в те поля) или выдает ошибку, в зависимости от настроек клиента. В нашем случае строка будет проигнорирована или загрузится с неверным количеством полей. 
*   *(Как сделать импорт повторяемым)*: перед загрузкой CSV нужно выполнить `DELETE FROM tools_stage`, иначе строки задвоятся.

## Часть 5. Заполнение табличного файла из массива (Выгрузка)
*   Прайс-лист каталога выгружен в файл `price_list.csv`.
*   В файле ровно **9** строк (1 заголовок + **8** строк с данными, что совпадает с `COUNT(*) FROM demo_tools`).
*   Круг замкнулся: при повторной загрузке `price_list.csv` в чистую таблицу количество строк будет **8**.
