# Отчет по ПР16. Массивы строк и ввод-вывод CSV

## Часть 1. Многострочный VALUES
*   Батч из 3 клиентов: `COUNT(*)` до вставки = 5, после = **8**. Проверка `ORDER BY id DESC LIMIT 3` возвращает 8, 7, 6.
*   **Ошибка при поломке кортежа:** При вставке 3 значений в 2 колонки СУБД SQLite выдает ошибку `3 values for 2 columns`. Вставка атомарна — ни одна строка не добавляется, `COUNT(*)` остается 8.
*   Свой батч из 3 выдач: до вставки `COUNT(*)` = 8, `SUM(deposit)` = 5450.0. После вставки = **11** и **7750.0**.

## Часть 2. INSERT ... SELECT
*   Перенос в архив: до переноса было 11 строк, сумма 7750.0. В архив `rentals_archive` отобралось 4 строки, сумма = **2900.0**. После удаления из `rentals` осталось 7 строк, сумма = **4850.0**.
*   **Контрольное равенство:** 4850.0 (остаток) + 2900.0 (архив) = **7750.0**. Ничего не потеряно.
*   Условие для закрытых выдач ноября (`return_date IS NOT NULL AND rent_date >= '2026-11-01'`) отбирает 1 строку.
*   Вставка через `UNION ALL` добавила 2 позиции. `COUNT(tools)` стало **10**.

## Часть 3. Временная таблица (Staging)
*   В буфер `stage_tools` загружено 6 строк. `COUNT(*)` = 6, `COUNT(DISTINCT name)` = **5**.
*   Дубль найден через `GROUP BY`: «Ключ разводной» встречается 2 раза.
*   Попытка переноса без чистки упала с ошибкой `UNIQUE constraint failed: tools.name` (вся вставка откатилась, COUNT = 10).
*   После удаления дубля (`DELETE WHERE s_id = 2`) перенос прошел успешно, вставилось 4 строки. Итоговый `COUNT(tools)` = **14**.
*   «Перфоратор» не попал в выборку, потому что он уже есть в основной таблице `tools`, и его отсеяло условие `WHERE name NOT IN (SELECT name FROM tools)`.

## Часть 4. Ввод-вывод CSV
*   В файле `tools.csv` оказалось **15** строк: 1 заголовок и 14 строк с данными. Тексты в файле экранированы двойными кавычками, разделитель — запятая.
*   Сверка после импорта в `tools_import`: `tools` (COUNT = 14, SUM = 6640.0) и `tools_import` (COUNT = 14, SUM = 6640.0). Числа совпадают.
*   **Ловушка заголовка:** При импорте без пропуска заголовка в таблицу с текстовыми колонками первая строка стала данными. `COUNT(*)` показал **15** (вместо 14). Лечится добавлением флага `--skip 1` или ручным удалением строки: `DELETE WHERE id = 'id'`.
